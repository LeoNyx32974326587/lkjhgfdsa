# RAIM – Landingpage (Nachbau)

Statische One-Page-Site, nur HTML/CSS/JS, kein Build nötig.

```
python3 -m http.server 8000   # dann http://localhost:8000 öffnen
```

- `index.html` – Inhalte (Hero, Features, Datenschutz, CTA, Footer)
- `styles.css` – Design (Dark/Violett, Glow-Buttons, Mockup-Karten)
- `script.js` – animierter Linien-Hintergrund, Neon-Logo, Waveform
- `assets/icon.svg` – App-Icon

Platzhalter: App-Store-Links (`href="#"`), Footer-Links und der Copyright-Name.
